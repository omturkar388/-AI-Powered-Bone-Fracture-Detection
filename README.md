# AI-Powered Bone Fracture Detection System

## Project Overview
A Deep Learning-based system that classifies bone X-ray images into Fractured and Non-Fractured categories using EfficientNetB0 and Transfer Learning.

## Technologies Used
- Python
- TensorFlow
- EfficientNetB0
- Deep Learning
- Computer Vision
- Grad-CAM
- FracAtlas Dataset

## Model Performance
- Accuracy: 84.79%
- Precision: 57.63%
- Recall: 53.97%
- F1-Score: 55.74%
- ROC-AUC: 0.8714%
